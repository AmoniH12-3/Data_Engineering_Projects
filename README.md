### [1_EDA — Exploratory Data Analysis](./1_EDA/)

**Highlights:**
- Analyzed remote Data Engineer job postings using DuckDB.
- Identified the most frequently requested technical skills.
- Compared median salaries across technologies.
- Developed a custom Salary-Demand Opportunity Score.

**Skills:** SQL, DuckDB, relational joins, aggregations, median calculations, analytical functions, data analysis, Git, and GitHub.
